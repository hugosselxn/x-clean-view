# X Clean View

Click the **X Clean View** toolbar icon to open settings. By default, the extension hides both sidebars and the floating Grok and Chat buttons, widens X's main column by 50%, and centers it in the browser window. The Left sidebar and Right sidebar switches can restore either column. Wide mode temporarily hides the left sidebar so the main view stays centered. Each left navigation item also has its own show/hide switch.

Settings are stored in this Chrome profile and apply to open X tabs immediately.

The **Switch to Twitter logo** option uses the supplied blue bird SVG for the logo at the top of X's left sidebar. It appears whenever the left sidebar is visible.

## Update an existing installation

1. Open `chrome://extensions`.
2. Click **Reload** on X Clean View.
3. Reload any open X tab once to start the updated content script.

## Install in Chrome

1. Open `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and select this `x-clean-view` folder.
3. Reload any open X tab.

Keep this folder in place while the unpacked extension is installed.
